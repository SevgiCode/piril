Small questions.
Clear answers.

A quick look at how the packages and demo calculator work.

What is included in the cleaning package?

The scope varies depending on the package you choose. The main items are listed on the service cards. Interior window cleaning is calculated with the optional extra in the form; exterior facades and high-access work are not included in these example packages.

How is the price calculated?

The demo calculator uses the package starting price for 50 m² and adds TRY 20 for every square meter above it. When a recurring service is selected, a sample discount is applied to the package amount. If window cleaning is selected, TRY 500 is added last. The minimum package price is based on 50 m².

Does completing the form create a reservation?

No. This website is a design demo. The form only summarizes the information you select on screen; it does not check availability, process payment, send data, or make a real reservation.

Can I choose recurring cleaning?

You can try the weekly or every-two-weeks option in the calculator. The amount shown is for one visit. In a real service, recurring dates, scope, and price must be confirmed separately.

How are supplies and special surfaces handled?

This demo does not guarantee that supplies are included. Before a real service, supply arrangements, delicate surfaces, access conditions, and special requests must be clarified separately.
